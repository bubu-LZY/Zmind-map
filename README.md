# Zmind-map v2.0.0

> 基于 [思绪思维导图 (mind-map)](https://github.com/wanglin2/mind-map) 二次开发的桌面端 AI 智能思维导图应用，由 AI 工具辅助开发。

一款集成了强大 AI Agent 系统的桌面思维导图工具，支持 AI 对话、智能挖空、自动复习计划、文件管理、多格式导出等功能。使用 Electron + Vue 2 构建，轻量高效，无需外部依赖。

## AI 智能功能（核心亮点）

### AI 对话系统

- **独立对话窗口**：AI 对话以独立悬浮窗口形式呈现，不遮挡思维导图编辑区
- **图片发送**：支持 Ctrl+V 粘贴图片发送给 AI，可单独发图、单独发文字、或图文一起发送
- **上下文引用**：可将思维导图中的节点添加到对话上下文，AI 自动理解节点层级关系
- **深度思考模式**：根据模型名自动识别并启用对应的推理参数格式（支持 DeepSeek-R1、Qwen-QwQ 等推理模型）
- **模型管理**：API 地址和密钥配置后自动检测可用模型列表，支持搜索和手动输入模型名
- **图片识别拦截**：当模型不支持图片识别时自动拦截并提示用户
- **多轮对话**：支持上下文多轮对话，自动维护对话历史
- **停止生成**：支持随时停止 AI 响应

### AI Agent 工具系统（v2.0.0 重点更新）

v2.0.0 版本的 AI Agent 系统支持 **61 个工具**，覆盖思维导图几乎所有操作，用户通过自然语言对话即可让 AI 自动完成各种任务。工具系统默认激活，无需手动切换智能体模式。

#### 工具调用机制

- **双模式支持**：原生 Function Calling（支持 `tools` 参数的模型）+ 提示词伪调用回退（如 DeepSeek-R1）
- **自动降级**：API 不支持原生工具调用时自动回退到提示词模式
- **权限确认**：编辑类操作弹出确认对话框，用户可批准或拒绝
- **Ctrl+Z 撤销**：所有 AI 操作支持 Ctrl+Z 撤销，恢复到操作前状态
- **批量执行**：一条回复中可同时调用多个工具，系统批量执行提高效率
- **超时看门狗**：120 秒超时保护，防止工具执行卡死

### AI 智能挖空

基于 AI 分析思维导图内容，自动选择关键词进行挖空（隐藏），辅助记忆和复习：

- **智能挖空模式**：保守策略，保留上下文线索，挖空后用户可通过剩余文字推断答案
- **激进挖空模式**：高强度策略，尽可能多挖空关键词，用于极限记忆测试
- **自动降级**：AI 挖空失败时自动回退到激进模式
- **批量处理**：支持对指定节点及其所有子节点批量挖空
- **版本保存**：支持保存多个挖空版本，便于切换不同挖空方案
- **持久化**：挖空状态保存到 localStorage，含 hiddenAll 和 nodeOverrideMap
- **动态并发**：大批量节点自动分批并行处理，遇限流自动降级

### AI 续写

- AI 根据当前节点内容自动续写，严格遵循参考知识，不自由发散
- 支持 Ctrl+Z 撤销，恢复到续写前状态

### AI 记忆系统

- **轻量自研方案**：不使用向量数据库，通过关键信息提取 + localStorage 存储
- **上下文注入**：每次对话提取关键信息，在后续对话中自动注入上下文
- **多文件支持**：记忆系统支持不同文件的独立记忆
- **低 Token 消耗**：通过一句话概括关键事实，避免 Token 浪费

### AI 配置

- **通用 OpenAI 兼容接口**：支持任何兼容 OpenAI API 格式的服务
- **模型自动检测**：输入 API 地址和密钥后自动获取可用模型列表
- **可搜索下拉**：模型选择支持手动输入和搜索
- **原生工具调用开关**：可开关原生 Function Calling（默认开启），自动回退到提示词模式

## 复习计划系统

基于艾宾浩斯遗忘曲线的智能复习计划：

- **9 个记忆周期**：按艾宾浩斯遗忘曲线自动安排 9 次复习时间
- **复习面板**：左侧日期列表 + 右侧节点列表，勾选标记完成
- **复习模式**：独立复习界面，入口动画（文字→球体→左移→展开面板）
- **节点跳转**：点击复习节点自动打开对应文件并高亮节点（红色边框含父子节点）
- **复习统计**：生成汇总图片，含当前日期的"今日待复习"中心节点
- **飞书提醒**：通过单个 Webhook 发送"忘记复习"和"定时提醒"通知
- **补发机制**：应用启动时检查错过的复习提醒并补发系统通知
- **系统托盘通知**：应用关闭时通过系统通知发送复习提醒
- **备份与清理**：复习计划备份到可配置的系统路径，已完成任务 3 个月自动清理
- **设置面板**：Webhook 配置、忘记复习触发时间、定时提醒时间
- **日期固定**：复习日期在添加时固定，不随后续操作改变
- **删除确认**：删除复习计划节点时弹出确认对话框

## 本地开发

### 环境要求

- Node.js 16+（推荐 18 LTS）
- npm 或 yarn

### 前端开发

```bash
cd mind-map/web
npm install
npm run serve    # 开发服务器
npm run build    # 生产构建
```

### 桌面应用打包

```bash
cd electron-app
npm install
npm run pack     # 打包 Windows x64 NSIS 安装程序
```

### 项目构建流程

1. 在 `mind-map/web/` 执行 `npm run build`，输出到 `mind-map/dist/`
2. 将 `mind-map/dist/` 内容复制到 `electron-app/app2/dist/`
3. 将 `mind-map/index.html` 复制到 `electron-app/app2/index.html`
4. 在 `electron-app/` 执行 `npm run pack` 生成 exe 安装包
